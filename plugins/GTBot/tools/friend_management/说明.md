# friend_management

这个插件为 GTBot 提供两类能力：

- 给 LLM 主动调用的好友删除工具：`delete_friend`
- 可选暴露给 LLM 的点赞工具：`send_like`
- 一个直接点赞命令：`/点赞`
- 一个带门槛的回赞命令：`/赞我`

## 配置

文件位置：

`plugins/GTBot/tools/friend_management/config.json`

字段说明：

- `enabled`
  - 是否启用删好友能力
  - 默认是 `false`
- `expose_like_tool_to_agent`
  - 是否把点赞工具 `send_like` 暴露给 Agent
  - 默认是 `false`
  - 该开关不影响手动 `/点赞` 命令
- `max_likes_per_user_per_day`
  - 机器人在单个北京时间自然日内，最多给同一个用户点多少个名片赞
  - 默认是 `10`
  - `0` 表示不限制
- `require_likes_before_zanwo`
  - 使用 `/赞我` 命令前，用户当天至少需要先给机器人点多少个赞
  - 默认是 `0`
  - `0` 表示不要求门槛
- `exempt_admin_for_zanwo_gate`
  - 机器人管理员和 owner 是否跳过 `/赞我` 的点赞门槛校验
  - 默认是 `true`
- `zanwo_gate_exempt_user_ids`
  - 额外跳过 `/赞我` 门槛校验的 QQ 号列表
  - 默认是空列表
- `api_action`
  - OneBot 动作名
  - 默认是 `delete_friend`
- `timeout_sec`
  - 调用超时时间
- `protected_friend_ids`
  - 受保护好友 QQ 号列表
  - 列表中的好友不会被工具删除
- `protected_friend_notes`
  - 受保护好友的备注说明
  - key 使用字符串形式的 QQ 号

示例：

```json
{
  "enabled": true,
  "expose_like_tool_to_agent": true,
  "max_likes_per_user_per_day": 10,
  "require_likes_before_zanwo": 3,
  "exempt_admin_for_zanwo_gate": true,
  "zanwo_gate_exempt_user_ids": [123456789],
  "api_action": "delete_friend",
  "timeout_sec": 15.0,
  "protected_friend_ids": [123456789, 987654321],
  "protected_friend_notes": {
    "123456789": "老板",
    "987654321": "测试保留账号"
  }
}
```

## 工具行为

- 当 `enabled=false` 时，工具会直接拒绝执行
- 当目标 QQ 号在 `protected_friend_ids` 中时，工具会拒绝删除
- 当 `expose_like_tool_to_agent=false` 时，点赞工具不会注册给 Agent
- 点赞能力会优先尝试一次发送 10 个赞；但若当天剩余额度不足，则只发送剩余额度允许的数量
- 每个用户的点赞计数按北京时间自然日统计，并在北京时间 0 点重置
- `/赞我` 会先查询用户当天给机器人点过多少个赞；若未达到 `require_likes_before_zanwo`，则拒绝执行
- `/赞我` 的门槛豁免规则先检查 `zanwo_gate_exempt_user_ids`，再按 `exempt_admin_for_zanwo_gate` 判断管理员是否自动放行
- 真正执行时，会调用：

```python
bot.call_api(api_action, user_id=target_user_id)
```

点赞工具调用：

```python
await Fun.send_like(bot, target_user_id, times=send_times)
```

## 命令

- `/点赞`
- `/赞我`

- `/点赞`：直接请求机器人给命令发起人点赞，不检查“你今天是否先给机器人点赞”门槛
- `/赞我`：会先检查你今天给机器人点过多少个赞，满足门槛后才会继续回赞
- 两条命令在真正发送时都会优先尝试点赞 10 次；如果当天剩余额度不足，则只发送剩余额度允许的数量

## 注意

- 这个插件默认是高风险能力，建议仅在你确认底层 OneBot 实现支持 `delete_friend` 时启用
- 如果你使用的实现动作名不同，可以修改 `api_action`
- Agent 侧的点赞暴露与删好友能力是两个独立开关，便于只开放低风险能力
